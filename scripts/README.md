# Importación local

`parse_mysql_dump.py` y `generate_import_sql.py` se usaron para transformar el SQL de InfinityFree. Los archivos generados con cuentas y respuestas históricas se mantienen fuera del repositorio porque contienen datos personales; la importación ya fue aplicada al proyecto Supabase EnglishMeme.

No ejecutar estos scripts con un dump que contenga contraseñas o tokens en un repositorio público. Los hashes antiguos de EnglishMeme se excluyeron deliberadamente.
